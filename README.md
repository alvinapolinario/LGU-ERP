# Integrated LGU Digital Government Platform

Modular platform for Philippine local government units: **paperless operations**, **ERP** (phased), **GIS**, **CDRA/CLUP**, and **executive decision support**.

This repository is in the **architecture phase**. Application code, database migrations, and Docker Compose files have not been generated yet.

## Documentation

Start here: **[docs/README.md](docs/README.md)**

The specification that produced the architecture is in [`prompt.md`](prompt.md).

## Current rule

Do not implement modules until the architecture in `docs/` is reviewed. The recommended first implementation prompt is [`docs/17-recommended-next-prompt.md`](docs/17-recommended-next-prompt.md).
